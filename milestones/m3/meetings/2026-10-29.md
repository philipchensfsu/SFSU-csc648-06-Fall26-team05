# Thursday Meeting Summary — October 29, 2026
We reviewed our progress toward M3 and discussed what still needs to be connected. The frontend team is working on the Tiptap document editor and coordinating with the backend team on the document format and editor layout. The backend work currently focuses on saving PRDs, defining document rules, and updating the database schema before moving on to features such as AI chat. The backend team will share its task breakdown so everyone knows who to contact about specific questions.

We discussed assigning owner, editor, and viewer permissions separately for each PRD, so someone can edit one document and only view another. Owners would manage document access, and assigned reviewers would be able to comment and approve without needing a separate organization-wide approval permission. We agreed that organization admins should have access to all PRDs for the current implementation. We also discussed allowing viewers to ask the AI questions about a document without changing it.

We agreed that saving a PRD should keep it as a draft until reviewers are assigned. Once reviewers are added, its status should change to “In Review.” Editing an approved PRD should return it to review, and we discussed clearing previous approvals and notifying reviewers when changes are made. Shared PRDs also need a clear place on the dashboard. Invitations and notifications will stay inside the application rather than sending real emails. The onboarding flow still needs clarification, particularly whether admins will create member accounts directly or members will join using a code.

For M3, we agreed to include a conversational AI chat and leave more advanced features, such as suggesting teams and proposing solutions to cross-department conflicts, for later milestones. Detailed progress tracking will also need further work. The AI team shared progress on the Gemini client, including timeout and retry handling, and the backend team confirmed access to the shared API project. The AI team will work on the model’s behavior, document context, and guardrails while coordinating with the backend team.We also reviewed the PR process and reminded everyone to address review comments and merge approved work so integration can move forward.
